IMPLEMENTATION NOTES

What the algorithms do

FILTER

Transform every pixel

The sepia operation calculates new red, green, and blue channel values while preserving the alpha channel.

QUANTIZE

Find the nearest colour

Each pixel is replaced by the closest entry in an eight-colour palette using squared Euclidean RGB distance.

RESAMPLE

Average a 4×4 block

Sixteen source pixels are averaged into one output pixel, reducing a 520×520 image to 130×130 without Canvas scaling.

Uploaded images stay in your browser and are not sent anywhere.
